# 仕分けの神様

スマホでレシートを撮影すると、AI（Claude）が日付・金額・摘要を読み取って、仕訳CSVにまとめるWebアプリです。

## 使い方
1. スマホでアプリのページを開く（初回はホーム画面に追加しておくと便利）
2. 初回だけ、右上の ⚙ 設定 から Anthropic の APIキーを登録する
   - キーはその端末のブラウザ内にだけ保存されます（このリポジトリには含まれません）
3. 開くとカメラが起動するので、レシートを続けて撮影 →「完了」
4. 一覧で内容を確認・修正して「CSVダウンロード」

## CSV の列（左から）
① 伝票日付 ② 借方科目コード ③ 借方補助コード ④ 借方金額 ⑤ 摘要 ⑥ 貸方科目コード ⑦ 貸方補助コード ⑧ 貸方金額

現在は ①④⑤⑧ を自動入力し、②③⑥⑦ は空欄（画面で手入力も可）です。

## 構成
- `docs/index.html` だけで動く静的アプリ（GitHub Pages で公開）
- 手元で試すとき: `cd docs && python3 -m http.server 3000` → http://localhost:3000
