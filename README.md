# 仕訳の神様

スマホでレシートを撮影すると、日付・金額・摘要を読み取って、仕訳CSVにまとめるWebアプリです。

- **無料モード（標準）**: スマホの中で文字を読み取る（Tesseract.js）。費用0円・画像は端末の外に出ない。精度は控えめ
- **高精度モード（任意）**: 設定でAnthropicのAPIキーを入れると、AI（Claude）で読み取る。1枚あたり数円

## 使い方
1. スマホでアプリのページを開く（初回はホーム画面に追加しておくと便利）
2. （任意）高精度モードを使う場合だけ、右上の ⚙ 設定 から Anthropic の APIキーを登録する
   - キーはその端末のブラウザ内にだけ保存されます（このリポジトリには含まれません）
3. 画面上部の会社名のボタンから、会社を登録・選択する（前回の会社を記憶）
4. 取り込み方法（①原始資料〔レシート・領収書。給与台帳・通帳は準備中〕／②現金預金収支日計表・③試算表入力は準備中）を選び、「撮影する」でレシートを撮影
5. 読み取った内容が一覧に並ぶので、間違いがあればその場で直す
6. 「CSVダウンロード」で一覧の分を出力（出力した分は一覧から外れ、格納済みとして端末内に保管）

## ③ 試算表入力（他の会計ソフトの試算表 → ミロク）
1. 「③ 試算表入力」を選び、「ファイルを選ぶ」から試算表のExcel・CSV・PDF・画像を選ぶ（または「撮影する」）。Excel・CSVは「借方」「貸方」の見出しから列を判断してそのまま読む
2. 各科目の「当月の借方・貸方」を、相手を諸口（反対側は空欄）にした仕訳にする。伝票日付は試算表の期間の末日
3. 元の科目 → ミロクの科目コードは、会社ごとの「対応表」で変換。初めての科目だけコードを選べば、次の月から自動
4. 借方合計と貸方合計が一致するかを画面上部に表示（ずれていれば読み取りか対応の間違い）
5. ミロクの科目マスタは標準のもの（121科目）が最初から入っている。会社ごとに違う科目（銀行口座など）は、会社の画面の「科目マスタ・対応表」で手直しする。CSVでの読み込み・書き出しもできる

## CSV の列（左から）
① 伝票日付 ② 借方科目コード ③ 借方補助コード ④ 借方金額 ⑤ 摘要 ⑥ 貸方科目コード ⑦ 貸方補助コード ⑧ 貸方金額

現在は ①④⑤⑧ を自動入力し、②③⑥⑦ は空欄（画面で手入力も可）です。

## 構成
- `docs/index.html` … 画面（Webアプリ）。GitHub Pages で公開し、iPhoneアプリの中でもそのまま使う
- `ios/` … iPhoneアプリ（Capacitor）。`ios/App/App/ShiwakeNative.swift` で次の機能をアプリに追加している
  - iPhone標準の文字認識（Vision）でレシートを読む（無料・端末内で処理）
  - 共有シートでCSVを保存する（「ファイルに保存」など）
- Webで開いた場合は、文字認識に Tesseract.js（無料・端末内）を使う

## 画面を変更したあとにアプリへ反映する
```
npm install        # 初回のみ
npx cap sync ios   # docs/ の内容をアプリにコピー
npx cap open ios   # Xcode を開く → 実行ボタンでiPhoneへインストール
```

## 手元で Web 版を試す
```
cd docs && python3 -m http.server 3000   # → http://localhost:3000
```
